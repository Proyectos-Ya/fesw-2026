Renders a Lucide icon inline; inherits `currentColor`. Load Lucide's UMD script on the page first.

```jsx
<Icon name="sparkles" size={18} />
<Icon name="search" size={20} color="var(--primary)" />
```

ProyectosYa uses Lucide at 2px stroke. Common names: `sparkles` (IA match), `search`, `target`, `file-text`, `bell`, `check`, `clock`, `building-2`, `arrow-right`.
